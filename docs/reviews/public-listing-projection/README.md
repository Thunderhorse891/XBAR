Prepared candidate only. Production SQL requires separate owner approval. This reconstructs an unpublished candidate whose local workspace was lost; earlier local validation is not reused as proof for this candidate.

A caller with an authorized public or token-protected listing can therefore receive internal cost basis, insurance, location, activity and future unknown fields. No customer record was queried.

The prepared SQL replaces only the existing legacy function body. The public wrapper, selected-row Live/release/token checks, function signature, owner and ACL stay intact. Unknown nested fields and malformed objects do not cross the boundary. Buyer media signing still receives the canonical workspace and approved storage path. Original documents and gallery files are untouched.
