# Executive ranch report acceptance review

The PDF now uses a dedicated, decision-oriented renderer. Other generated legal documents retain their existing layout. The original 18-horse synthetic fixture remains three US Letter pages; larger registers receive titled continuation pages and repeated table headers. No record rows are deliberately omitted to force a three-page limit.

| Requested change                                   | Implemented behavior                                                                                                                                                                                                                                                                                          |
| -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Compact branding, data dominates                   | Small original horse logo; print watermark at 1.8% in masthead only; thin brand rule; smaller XBAR TM footer.                                                                                                                                                                                                 |
| Seven financial KPI cards                          | Invested, Listed Value, Potential Margin, Monthly Burn, Sale-Ready Value, Blocked Value, Open Offers.                                                                                                                                                                                                         |
| Executive summary, blocked money, zero ready value | Prominent warning band, blocked share and ready-to-close amount; current spending and overhead narrative.                                                                                                                                                                                                     |
| Data-supported changes                             | Current month is identified. No historical portfolio change is invented: absence of a prior snapshot is stated.                                                                                                                                                                                               |
| Top actions                                        | Derived from ownership, Coggins, transfer, medical-review and document-queue blockers, overhead and projected profit. Overlapping blockers never promise that one action alone unlocks the full asking value.                                                                                                 |
| Page 2 readiness management                        | Blocked count/value, missing ownership/Coggins counts, queued file count, and readiness bar. Compact seven-column register, blocked first then asking price.                                                                                                                                                  |
| Missing vs review                                  | No ownership record = not started; no Coggins file = missing; an existing pending file = review. Current-date problems are identified separately.                                                                                                                                                             |
| 80% profile score vs zero ready                    | Stored profile score is explicitly distinct from sale gates. The data has no per-point weighting breakdown, so the missing 20 points are not falsely attributed to specific blockers. Recorded sale gates are listed per horse.                                                                               |
| Page 3 economics                                   | Eight financial columns, sale inventory first then projected profit descending, deterministic ties, and blocked/ready/not-sale status indicators.                                                                                                                                                             |
| Margin indicators                                  | H >=30%, M 15-29%, L <15%, with color and text; uses the existing rounded projected-margin percentage.                                                                                                                                                                                                        |
| Charts                                             | Invested vs listed, blocked vs ready asking value, readiness counts, margin distribution and spend categories. Single-category spend stays compact.                                                                                                                                                           |
| Burn transparency                                  | Prior three complete months, excluding the current month. Current receipts and current unallocated overhead are stated separately. Zero recorded burn is not described as free care.                                                                                                                          |
| Financial basis                                    | Investment includes acquisitions and receipts. Horse break-even adds two months of historical horse burn. Profit is asking less break-even; floor adds 15%. Unallocated overhead, fees and taxes are excluded from projected horse margins. Values displayed in whole USD; this is not an appraisal or audit. |
| Premium structure                                  | Separate section openers, consistent type/color hierarchy, aligned numbers, zebra rows, compact dividers, status indicators and explicit actions.                                                                                                                                                             |
| Complete data at scale                             | All horses and categories retained; additional actions, categories and spend anomalies receive deliberate appendix pages as needed.                                                                                                                                                                           |

## Verification

- Dedicated PDF tests inspect actual rendered operators and page bounds for the 18-horse sample, empty workspace, and 75-horse register with long names.
- Assertions cover the three-page sample, seven cards, blocked dollars, complete economics rows, nonoverlapping footer area, current vs prior-month costs, unallocated overhead, sale-only margin scope, and missing-vs-review actions.
- Verified locally: 1,180 unit checks including five dedicated report tests; TypeScript; actual registration-to-PDF/CSV browser exports at desktop and mobile widths. Final GitHub CI also checks the combined branch with Claude changes.
- Final three-page synthetic sample rendered with Poppler and all pages visually inspected for alignment, legibility and clipping. Automated bounds checks also cover larger reports.

Remaining product limits are explicit: profile-score point weights and prior portfolio snapshots are not available in the report model. This redesign does not invent them, certify accounting completeness, establish legal registration, or resolve unrelated app launch blockers.
